# Compare options

Help the user make a decision without hiding assumptions or flattening meaningful tradeoffs.

1. State the decision being made and the outcome the user wants.
2. List the available options. Do not invent additional options unless the user asks for alternatives.
3. Identify the material constraints and evaluation criteria. Clearly label any inferred criterion and ask before assigning a consequential priority the user has not provided.
4. Compare each option against the same criteria. Distinguish known facts from estimates, assumptions, and unresolved questions.
5. Explain the strongest advantage, strongest drawback, and important failure condition for each option.
6. Recommend an option only when the evidence supports one. Otherwise, explain what missing information would change the decision.
7. End with one concrete next step that moves the decision forward.

Use a compact table when it makes repeated comparisons easier to scan. Do not manufacture numerical scores or weights merely to create an appearance of precision.
